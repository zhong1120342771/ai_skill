# 分析图表风格指南

**面向 AI Analytics for Builders 课程所有视觉素材的内部参考。**
基于 Cole Nussbaumer Knaflic 的 *Storytelling with Data*（SWD）原则。

---

## 理念

本课程的每张图表都遵循一条规则：**一图一事。**

- 标题陈述要点，而非描述
- 把一切灰化，再高亮唯一重要的那一点
- 如果一张图不改变某个决策，就删掉
- 单个数字宁用文本，不用图表
- 每个视觉元素都必须物有所值 —— 若无助于读者理解故事，就移除

## 配色

默认使用灰色。颜色只留给讲述故事的那个数据点。

| 名称 | Hex | 用途 |
|------|-----|-------|
| **Action Amber** | `#D97706` | 主高亮 —— 唯一需要聚焦的那一点 |
| **Accent Red** | `#DC2626` | 次要 —— 负向趋势、下滑、警示 |
| **Gray 900** | `#1F2937` | 标题、关键文字 |
| **Gray 600** | `#6B7280` | 坐标轴标签、次要文字 |
| **Gray 400** | `#9CA3AF` | 网格线、边框（谨慎使用） |
| **Gray 200** | `#E5E7EB` | 背景数据 —— 非焦点的柱/线 |
| **Gray 100** | `#F3F4F6` | 细微填充、底纹 |
| **Background** | `#F7F6F2` | 图表与幻灯片背景 —— 暖米白 |

### 语义色（仅在含义明确时使用）

| 名称 | Hex | 用途 |
|------|-----|-------|
| **Success Green** | `#059669` | 正向结果、改善 |
| **Warning Amber** | `#D97706` | 警示、接近阈值 |
| **Danger Red** | `#DC2626` | 负向结果、失败、下滑 |

### 规则

- **单张图表中颜色绝不超过 2 种**（外加灰色）
- **绝不单靠颜色**编码含义 —— 要配合标签或标注
- **彩虹配色被禁用** —— 它们制造视觉噪音且没有自然排序
- Action Amber 是默认高亮；只有在语义需要时才切换为红/绿
- Action Amber 与演示主题的强调色（`--accent: #D97706`）一致，确保图表在视觉上融入幻灯片

**主题集成：** 图表颜色派生自 Marp 主题的 CSS 设计 token（`themes/analytics-light.css`）。背景为 `--bg: #F7F6F2`，边框用 `--border: #E5E7EB`，标签用 `--text-secondary: #4B5563`，标题用 `--text: #1F2937`。这让图表与幻灯片浑然一体，而非生硬贴入。

### 无障碍

Action Amber / Accent Red / 灰色配色经过设计，对色觉缺陷友好。在绿色盲和红色盲模拟下，琥珀色（#D97706）和红色（#DC2626）仍可区分。为保持这一点：

- 颜色始终配合第二条视觉通道（直接标签、图案、位置或粗细）
- 绝不单靠颜色传达含义
- 当 Success Green（#059669）与 Accent Red 并用时，确保两者都直接标注 —— 绿/红是色盲观众最难区分的一对

#### 图案与纹理建议

当图表可能以灰度打印或被色盲用户查看时，添加图案填充作为次要编码通道：

- **高亮柱：** 实心填充（Action Amber）—— 因始终配有直接标签，无需图案
- **对比分组：** 用斜线图案区分各组：
  - 组 1：实心填充
  - 组 2：斜线斜纹（`//`）
  - 组 3：交叉斜纹（`xx`）
  - 组 4：点状图案（`..`）
- **堆叠柱段：** 当层数超过 2 时，相邻段在实心与浅斜纹之间交替
- 在 matplotlib 中，通过 `bar(..., hatch='//')` 或 `Rectangle(..., hatch='xx')` 添加斜纹

#### 字号下限

图表中所有文字都必须满足最小字号要求，以保证在标准观看距离和投影时清晰可读：

| 元素 | 最小字号 | 推荐字号 |
|---------|-------------|-----------------|
| **图表标题** | 14pt | 17-18pt |
| **坐标轴标签** | 11pt | 11-12pt |
| **刻度标签** | 9pt | 10pt |
| **数据标签 / 标注** | 9pt | 9-10pt |
| **图例文字** | 8pt | 9pt |

#### 幻灯片图表尺寸

图表以标准 figsize `(10, 6)`（约 1500×900 @ 150 DPI）渲染，并直接嵌入幻灯片。主题中的 CSS `object-fit: contain` 处理所有容纳逻辑 —— 无需在图表侧调整尺寸。

```python
from helpers.chart_helpers import CHART_FIGSIZE

fig, ax = plt.subplots(figsize=CHART_FIGSIZE)  # (10, 6)
# ... build chart ...
save_chart(fig, "outputs/charts/my_chart.png")
```

#### 日期轴格式

时序图表必须显示可读的日期标签。Matplotlib 默认的 `AutoDateFormatter` 常生成 "-01, -02" 这类片段，而非月份名。绘图后使用 `format_date_axis()`：

```python
from helpers.chart_helpers import format_date_axis

# After plotting time-series data:
format_date_axis(ax)           # Default: abbreviated month (Jan, Feb, Mar)
format_date_axis(ax, "%b %Y")  # Month + year (Jan 2024)
format_date_axis(ax, "%b '%y") # Short year (Jan '24)
```

该函数同时处理 datetime 类型轴和字符串日期轴。对字符串轴，它会尝试用 `pd.to_datetime()` 解析标签并重新格式化。若解析失败，轴保持不变。

**规则：** 每张带日期/时间 x 轴的图表，保存前必须调用 `format_date_axis(ax)`。这一项会在去杂检查清单中核对（步骤 5b，第 10 项）。

#### 标题间距规则

`action_title()` 使用 `transAxes` 坐标定位标题和副标题：

| 元素 | Y 位置 | 字号 |
|---------|-----------|-----------|
| 标题 | `y=1.12` | 17pt 粗体 |
| 副标题 | `y=1.06` | 12pt 常规 |

0.06 的间隙（1.12 − 1.06）提供了足够的分隔。

#### 对比度要求

文字和视觉元素必须满足 WCAG 2.1 对比度：

| 元素类型 | 最小对比度 | 备注 |
|-------------|----------------------|-------|
| **正文文字**（坐标轴标签、标注、数据标签） | 4.5:1 | 相对背景色 |
| **大号文字**（标题、≥18pt 的大数字） | 3:1 | 相对背景色 |
| **非文字元素**（柱、线、数据点） | 3:1 | 相对相邻元素 |
| **热力图单元格文字** | 4.5:1 | 相对单元格背景 —— 自动切换白/深色 |

配色已针对 `#F7F6F2` 背景预先验证：
- Gray 900（`#1F2937`）于背景上：约 12:1（通过）
- Gray 600（`#6B7280`）于背景上：约 5:1（通过）
- Action Amber（`#D97706`）于背景上：约 4.6:1（通过）
- Gray 400（`#9CA3AF`）于背景上：约 3.2:1（仅大号文字通过）
- Gray 200（`#E5E7EB`）于背景上：约 1.3:1（仅装饰用 —— 绝不用于文字）

#### 图表替代文本（Alt Text）指南

每张保存到 `outputs/` 的图表都应配有替代文本描述。替代文本让屏幕阅读器可访问，也充当文档。

**结构：** 类型 + 数据 + 洞察

1. **图表类型：** 说明它是哪种图（柱状图、折线图等）
2. **数据描述：** 概括展示了什么数据（坐标轴、类别、时间范围）
3. **关键洞察：** 陈述主要要点（与行动标题一致）

**示例：**

- "横向柱状图，按类别展示工单量。支付问题以 2,450 张工单居首，其次是物流（1,200）和账户（890）。支付问题推动了 6 月的激增。"
- "折线图，展示 2024 年 1 月至 12 月的月活用户。iOS 用量 6 月飙升至 45,000，而 Android 稳定在 28,000。"
- "斜率图，对比改版前后 5 个产品分群的 NPS。企业版 NPS 从 32 升至 58，变化最大。"

**规则：**
- 替代文本控制在 150 词以内
- 始终包含高亮数据点的数值
- 不要描述颜色 —— 描述关系或模式
- 适用时包含时间范围或日期背景
- 让替代文本的要点与图表的行动标题一致

## 去杂检查清单

定稿任何图表前，移除或削减：

- [ ] **图表边框 / 方框** —— 完全移除
- [ ] **上边框与右边框** —— 移除（仅保留下边框和左边框）
- [ ] **粗网格线** —— 移除，或用极浅灰（`#E5E7EB`），仅 y 轴
- [ ] **数据标记点** —— 从折线图中移除（线本身*就是*数据）
- [ ] **图例** —— 用数据上的直接标签替代
- [ ] **旋转的坐标轴文字** —— 若标签需要旋转，改用横向柱状图
- [ ] **末尾的零** —— 用 `$45` 而非 `$45.00`；用 `12%` 而非 `12.0%`
- [ ] **3D 效果** —— 永不使用
- [ ] **背景色** —— 始终为 `#F7F6F2`（与幻灯片主题一致）
- [ ] **冗余的坐标轴标签** —— 若标题写了 "Revenue ($M)"，y 轴就不必再写 "Revenue in Millions of Dollars"
- [ ] **过多刻度** —— 削减到最多 4-6 个刻度
- [ ] **小数精度** —— 让精度匹配决策（`12%` 足够时不要显示 `12.347%`）

## 图表类型决策树

根据你要展示的关系选择图表类型：

### 时序 → 折线图
- 用 Action Amber 高亮讲述故事的那一条序列
- 灰化所有其他序列
- 在每条线末端使用直接标签（不用图例）
- 例："iOS 工单量飙升而 Android 保持稳定"

### 类别对比 → 横向柱状图
- 按数值排序（最大在上），而非按字母
- 用 Action Amber 高亮重要的柱，其余灰化
- 在柱末端使用直接标签（不需要 x 轴）
- 例："付费搜索带来的转化是社交的 3 倍"

### 漏斗 → 横向柱状图或瀑布图
- 从左到右或从上到下展示各阶段
- 在阶段间标注流失百分比
- 用 Accent Red 高亮最大的流失
- 例："移动端结账是我们流失 40% 用户的地方"

### 前后对比或双期对比 → 斜率图
- 左侧 = 之前，右侧 = 之后
- 高亮变化最大的那条线
- 灰化未变化的线
- 例："NPS 在两个分群都改善了，但结构发生了变化"

### 部分与整体 → 堆叠柱状图（横向）
- 把重要的段放在基线（底部/左侧）
- 上下文段用灰色，故事用颜色
- **绝不用饼图** —— 堆叠柱总是更精确
- 例："Plus 会员现占收入 60%，高于此前的 40%"

### 单个数字 → 加粗大字
- 不要为单个数字画图 —— 用大号格式化文本展示
- 用副标题补充背景：方向、对比或基准
- 例：**"$75"** 平均客单价（环比 Q1 +12%）

### 实验结果 → 并排柱状图
- 对照组（灰色）vs 实验组（Action Amber）
- 用误差棒展示置信区间
- 标注提升百分比
- 例："实验组将转化提升了 8%（95% CI：3-13%）"

### 分布 → 直方图
- 连续数据使用 15-25 个分箱
- 若某个区域是故事，则高亮该区域
- 为均值/中位数加一条带标注的竖线

### 类别 × 分组对比 → 分组柱状图
- 当跨类别 AND 跨分组对比数值时使用（如各季度按地区的收入）
- 若某一组是故事，则高亮它并灰化其余
- 每根柱顶端直接标注；字号保持小（8pt）以免拥挤
- 最多限制到 4-5 组 —— 超出则改用 small multiples

### 双期变化 → 斜率图
- 当跨多个项目对比恰好两个时间点时使用
- 用 Action Amber 高亮变化最大的线
- 灰化所有其他线，让它们提供背景而不分散注意
- 在两端用数值标注，便于精确读数
- 最适合 5-15 个项目 —— 更少会失去对比效果，更多则成意大利面

### 留存队列 → 热力图
- 用于留存三角、队列对比矩阵，或任意行列度量网格
- 默认 colormap：红到绿插值（低留存 = 红，高留存 = 绿）
- 备选：`cmap="YlOrRd_r"` 用于暖色调留存着色
- 右删失单元格（未来周期）显示为 Gray 100
- 单元格文字在深背景上为白色，在浅背景上为深色

### 双变量敏感性 → 敏感性表
- 用于机会测算中的假设压力测试
- 基准情形单元格用粗边框；盈亏平衡单元格用虚线边框
- 颜色渐变：红（最差）经白（中点）到绿（最佳）
- 单元格格式保持一致（如全为 `$X,XXX` 或全为 `X%`）
- 两轴都标注变量名和单位

### 漏斗流失 → 漏斗瀑布图
- 用于展示逐步转化及明确的流失率
- 自动高亮绝对流失最大的步骤
- 在步骤间标注转化率和流失率
- 柱为横向，从上到下排序（入口在上，出口在下）
- 步骤标签保持简短、行动导向（"访问""注册""激活"）

### KPI 汇总 → 大数字布局
- 当故事是单个数字或 2-4 个 KPI 时使用 —— 而非数据分布
- 大数字根据数量用 28-36pt 字号（4 个以上时缩小）
- 每个指标下方有 Gray 600 的标签
- 分隔线把指标行与发现和建议分开
- 以要点形式列出关键发现，并用 Action Amber 给出建议

### 预测（未来） → 预测图
- 实线表示实际值，虚线表示预测/预报值
- 置信区间带为阴影区域（Alpha 0.15-0.25）
- 预测线用 Action Amber，实际值用 Gray 400
- 在实际与预测的过渡点处标注
- 用逐渐变浅的阴影展示 80% 和 95% 置信带

## 图表函数样式规范

每个图表辅助函数的详细渲染规范。在定制或扩展图表函数时使用这些规范。

### grouped_bar()

| 属性 | 取值 |
|----------|-------|
| **柱宽** | 每根柱 `0.7 / n_groups` |
| **柱间间隙** | 柱宽的 10%（组内） |
| **组间间隙** | 自动（matplotlib 默认刻度间距） |

| **高亮处理** | 高亮组用 Action Amber（`#D97706`），其余用 Gray 200（`#E5E7EB`） |

| **标签颜色（非高亮）** | Gray 400（`#9CA3AF`） |
| **最大组数** | 推荐 4-5；超出则用 small multiples |

| 属性 | 取值 |
|----------|-------|
| **线宽（高亮）** | 2.5pt |
| **线宽（背景）** | 1.5pt |

| **标签对齐（左）** | 右对齐，从 x=0 偏移 -0.08 |
| **标签对齐（右）** | 左对齐，从 x=1 偏移 +0.08 |
| **高亮标签** | 10pt、粗体、Action Amber |
| **背景标签** | 9pt、常规、Gray 400 |
| **竖直参考线** | Gray 200，0.8pt，位于 x=0 和 x=1 |
| **Y 轴** | 隐藏（数值显示为端点标签） |
| **理想项目数** | 5-15 项 |

### retention_heatmap()

| 属性 | 取值 |
|----------|-------|
| **默认 colormap** | 线性插值：红（`#DC2626`）到绿（`#059669`） |
| **备选 colormap** | `cmap="YlOrRd_r"` 用于暖色调留存 |
| **标注格式** | 默认 `"{:.0%}"` —— 如 "85%" |
| **单元格边框** | 白色（`#FFFFFF`），1pt |
| **NaN 单元格填充** | Gray 100（`#F3F4F6`） |
| **深色单元格文字** | 白色（`#FFFFFF`），9pt，粗体 |
| **浅色单元格文字** | Gray 900（`#1F2937`），9pt，粗体 |

## 分析方法图表样式契约

分析方法输出中常用图表的样式契约。
这些契约确保分群、分布、相关性和排名分析之间的一致性。

### 分布图（直方图 + KDE 叠加）

用于展示单个变量分布的形状。

| 属性 | 取值 |
|----------|-------|
| **分箱** | 连续数据 15-25 个；回退时用 `bins="auto"` 自动分箱 |
| **柱色** | Gray 200（`#E5E7EB`），Gray 400 边（`#9CA3AF`），0.5pt |
| **KDE 叠加** | Action Amber（`#D97706`），2pt 实线，绘于次 y 轴或按密度缩放 |
| **均值/中位数线** | 竖直虚线，1.5pt，均值用 Accent Red，中位数用 Gray 600 |
| **均值/中位数标注** | 9pt，置于线顶部并带数值标签 |
| **高亮区域** | `axvspan`，Action Amber，alpha 0.12 |
| **Y 轴** | 标为 "Count" 或 "Frequency"；若仅 KDE 则隐藏 |
| **X 轴** | 标注变量名和单位 |

### 对比图（用于分群对比的分组柱）

用于跨共享指标的分群并排对比。

| 属性 | 取值 |
|----------|-------|
| **布局** | 使用 `grouped_bar()` 函数 |
| **分群排序** | 最大分群在前（按时间则按时序） |
| **高亮** | 把 `highlight_group` 设为讲述故事的分群 |
| **误差棒** | 若有置信区间，加为细线（1pt，Gray 600） |
| **基线参考** | 可选的整体均值横向虚线（Gray 400，1pt） |
| **最大分群数** | 4-5；超出则用 small multiples |

### 相关性图（带趋势线的散点图）

用于展示两个连续变量之间的关系。

| 属性 | 取值 |
|----------|-------|
| **点色** | 所有点用 Gray 200（`#E5E7EB`） |
| **点大小** | 30-50（matplotlib `s` 参数）；若为气泡图则按第三个变量缩放 |
| **高亮点** | Action Amber（`#D97706`），略大（50-70） |
| **趋势线** | 使用 `add_trendline()` —— 虚线，1pt，Gray 400 |
| **R 方标注** | 9pt，置于左上或右下角，Gray 600 |
| **轴标签** | 10pt，Gray 600，含单位 |
| **网格线** | 浅色 y 轴和 x 轴网格线（Gray 200，0.5pt） |

### 排名图（按量级排序的横向柱）

用于展示按单一指标排名的项目。

| 属性 | 取值 |
|----------|-------|
| **布局** | 使用 `highlight_bar()`，参数 `horizontal=True, sort=True` |
| **柱方向** | 横向（类别名在 y 轴，数值在 x 轴） |
| **排序** | 升序（最小在上，最大在下）—— matplotlib 惯例，便于阅读 |
| **Top-N 高亮** | 用 Action Amber 高亮前 1-3 项，其余 Gray 200 |
| **直接标签** | 置于柱末端，9pt，数值格式与指标匹配 |
| **X 轴** | 隐藏（数值显示为直接标签） |
| **最大项目数** | 10-15；超出则展示 "Top 10" 并注明总数 |

## 标题与标注规则

### 标题讲述故事

每个图表标题都应是**行动标题** —— 一句陈述要点的话。

| 类型 | 示例 |
|------|---------|
| **描述式（差）** | "Monthly Support Tickets by Category" |
| **行动式（好）** | "Payment issues drove the June ticket spike" |
| **描述式（差）** | "Conversion Rate by Device" |
| **行动式（好）** | "Mobile converts at half the rate of desktop" |
| **行动式（好）** | "Ticket rate climbed 4x — independent of business growth" |

### 字体层级

| 元素 | 字重 | 字号 | 颜色 |
|---------|--------|------|-------|
| **标题** | 粗体 | 17pt | Gray 900（`#1F2937`） |
| **副标题** | 常规 | 12pt | Gray 600（`#6B7280`） |
| **坐标轴标签** | 常规 | 10pt | Gray 600（`#6B7280`） |
| **标注** | 常规 | 9pt | Gray 900 或 Action Amber |
| **数据标签** | 常规 | 9pt | 与数据元素颜色一致 |

### 标注准则

- 把标注放在它所引用的数据点**附近**
- 只有当标签无法直接落在数据上时才用一根细箭头
- 标注文字保持简短（10 词以内）
- 标注对齐保持一致（全左、全右或全居中）
- 不要标注一切 —— 只标注支撑故事的内容

## 故事结构

多图分析（深度剖析、根因调查）遵循 **背景 → 张力 → 化解**：

### 背景（1-2 张图）
确立基线。正常是什么样？
- "[数据集] 每月处理约 4,000 张工单"
- 用简单的时序图或汇总统计

### 张力（2-3 张图）
揭示问题。什么变了，在哪里变？
- "6 月，工单飙升至 6,200 —— 增长 55%"
- "激增集中在 iOS 支付问题"
- 用逐步聚焦的图表放大异常

### 化解（1-2 张图）
解释原因并建议行动。
- "iOS app 2.3 版引入了一个支付处理 bug"
- "修复该 bug 可消除每月约 2,200 张工单"
- 以建议收尾，而非仅停于发现

### 排序规则

- 每张图都应建立在前一张之上
- 绝不展示让受众发问"那又怎样？"的图
- 最后一张图应让推荐的行动显而易见
- 一次完整分析限制在 4-6 张图（而非 12 张）

## 反模式

以下在所有课程材料中**被禁用**：

| 反模式 | 为何不好 | 改用 |
|--------------|-------------|------------|
| **饼图** | 人难以准确对比角度 | 横向柱状图 |
| **彩虹配色** | 无自然排序、视觉噪音 | 灰色 + 一种高亮色 |
| **意大利面折线** | 太多彩色线，无一突出 | 灰化所有线，高亮一条 |
| **双 y 轴** | 误导 —— 任意两条序列都能被做成"相关" | 两张独立图，纵向堆叠 |
| **3D 图表** | 扭曲比例，不增信息 | 扁平 2D 版本 |
| **描述式标题** | 不告诉读者该怎么想 | 行动标题（陈述要点） |
| **图例框** | 迫使读者把视线移开数据 | 数据上的直接标签 |
| **过多网格线** | 制造视觉杂乱 | 仅浅色 y 轴网格线，或全无 |
| **截断 y 轴** | 夸大微小差异（柱状图） | 柱状图从零开始 |
| **杂乱标注** | 标注每个数据点失去意义 | 只标注故事 |

## 常见坑

图表制作中发现的实际问题。定稿前请核对这些。

### 同比对比 —— 不要用两根相似的柱

两种灰度（或两种柔和色）的并排柱几乎无法区分。对于同比或环比对比：

- **使用叠加折线**，当前期用 Action Amber，前期用 Gray 200
- **加 `fill_between`** 给两线之间的间隙着色（Gray 100，alpha 0.3）
- **使用线末标签**显示期间和总量（如 "2024 (9.5M)"）
- 并排柱仅保留给柱具有不同高亮色的类别对比

### 负值柱标签 —— 给坐标轴留白

当柱状图含负值时，置于柱末端外侧的直接标签可能与对侧轴上的类别名碰撞：

- 从数据计算 `x_min` 和 `x_max`，再设 `ax.set_xlim(x_min - padding, x_max + padding)`
- 负值柱把标签放在柱末端左侧；正值柱放右侧
- 2-3 个百分点（对 % 数据）或范围的约 10% 的留白效果较好

### 背景事件 —— 要醒目

解释异常的外部事件（产品发布、宕机、山火、政策变化）必须在视觉上醒目。一个小灰色标注箭头不够：

- 使用带彩色边框的 **bbox 标注**：`bbox=dict(boxstyle="round,pad=0.4", fc="white", ec=COLORS["accent"], lw=1.5)`
- 把标注放在视线自然落点（受影响数据点附近）
- 文字简短具体："Lahaina wildfire (Aug 2023)"，而非 "External event occurred"

### 标注碰撞 —— 改用直接标签

当多个数据点彼此靠近时（如连续几个月都标注），箭头式标注会堆叠、变得难读：

- **去掉箭头** —— 用置于每根柱或点正上方/下方的直接标签
- 若只有一个点是故事，只标注它，让其余自己说话
- 用语义色（如最差月份用 Danger Red）来吸引视线，而非用箭头

### 标注与标签碰撞 —— 保存前检查

在同时带有直接数据标签的图表上使用 `annotate_point()` 时，箭头和文字可能与已有标签重叠：

- 添加标注前，检查是否有已存在的数据标签占据同一区域
- 若碰撞：(1) 移动标注偏移量，(2) 去掉箭头改用颜色强调，或 (3) 移除碰撞点处的数据标签
- 在最终 DPI 下测试 —— 在屏幕分辨率下看似正常的碰撞，在 150 DPI 下可能重叠

### 多面板图表 —— 绕过 `tight_layout()`

`save_chart()` 内部会调用 `fig.tight_layout()`，它会覆盖手动的 `fig.subplots_adjust()` 和 `fig.text()` 定位。对于以下图表：

- **图级标题**（通过 `fig.text()`）
- **手动 `subplots_adjust(top=...)`** 为这些标题腾出空间
- **多个子图**各自带面板标题

改用直接的 `fig.savefig()` 而非 `save_chart()`：

```python
fig.savefig(path, dpi=150, bbox_inches="tight", facecolor="#F7F6F2", edgecolor="none")
plt.close(fig)
```

这能保留你的手动间距。只在 `tight_layout()` 有帮助的单面板图表上使用 `save_chart()`。

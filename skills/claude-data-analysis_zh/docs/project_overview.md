# 项目概览

## 愿景与使命

Claude 数据分析助手致力于让数据分析人人可及，提供一个智能、易用的平台，把 AI 的能力与现代数据科学工具结合起来。我们的使命是让从初学者到资深数据科学家的每个人都能用上成熟的数据分析能力。

## 架构概览

### 核心组件

#### 1. 子代理系统
处理数据分析各个环节的专用 AI 代理：

- **Data Explorer**：统计分析与模式发现
- **Visualization Specialist**：图表制作
- **Code Generator**：分析代码生成
- **Report Writer**：完整报告生成
- **Quality Assurance**：数据校验与质量控制
- **Hypothesis Generator**：研究假设与洞察

#### 2. 斜杠命令界面
面向数据分析的直观命令行界面：

- `/analyze`：执行数据分析
- `/visualize`：创建可视化
- `/generate`：生成分析代码
- `/report`：生成报告
- `/quality`：质量保证
- `/hypothesis`：生成假设

#### 3. 自动化钩子
用于数据处理的自动化工作流：

- 上传时的数据校验
- 贴合情境的分析建议
- 自动质量检查
- 与外部工具集成

## 设计原则

### 1. 以用户为中心
- **直观界面**：用简单命令完成复杂分析
- **渐进式呈现**：从简单开始，按需展开复杂度
- **情境感知**：理解用户意图和项目背景
- **反馈闭环**：基于使用情况持续改进

### 2. 技术卓越
- **模块化架构**：组件独立、可替换
- **可扩展性**：处理各种规模的数据集
- **性能**：快速、响应及时的分析
- **可靠性**：结果一致、可复现

### 3. 可扩展性
- **插件式架构**：易于新增代理和命令
- **开放标准**：兼容现有数据科学工具
- **API 优先**：为集成和自动化而设计
- **社区驱动**：欢迎贡献与扩展

## 技术栈

### 核心技术
- **Claude Code**：AI 平台与子代理框架
- **Python**：数据分析主力编程语言
- **数据科学库**：Pandas、NumPy、Scikit-learn、Matplotlib
- **可视化库**：Seaborn、Plotly、D3.js
- **Web 技术**：HTML、CSS、JavaScript，用于交互式输出

### 配套技术
- **数据库支持**：SQLite、PostgreSQL、MySQL 集成
- **云服务**：兼容 AWS、Google Cloud、Azure
- **容器支持**：Docker 用于一致的部署
- **版本控制**：Git 集成实现可复现分析

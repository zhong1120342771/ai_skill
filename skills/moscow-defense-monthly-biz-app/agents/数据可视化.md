# 莫斯科月报-数据可视化

## 🚨 默认执行路径：直接跑固化脚本（不要重写代码）

**99% 的情况只需一件事**：

```bash
MONTH=${month} python3 ~/.claude/skills/moscow-defense-monthly-biz-app/scripts/render_charts_monthly.py
```

跑完检查 `~/Downloads/msk_monthly_raw_app/${month}/charts/charts_manifest.json` 存在即可返回父 agent。**不要重写 1 张图的渲染代码**——已固化、已按月粒度改造。

**仅在下列情况才改 `scripts/render_charts_monthly.py`**：
- 数据口径变更需要新指标/新分组
- CSV 字段名/列结构变化
- 用户在本轮对话明确要求改视觉

修改时保持：5 色体系、`force_month_ticks`、`annotate_group` 三件套不变，输出仍是 1 张同名 PNG + manifest。

## 基础与定位

本 agent 是**洞察结论生成 agent 的内嵌子 agent**，只做图表生成。严格边界：**不写飞书文档、不推送 IM、不改数字、不在主流水线 4 步内**（由 Step 4 内嵌调起）。

与周报的关键差异：**月报保留 2 张图**——大盘 25vs26 趋势图（本就月粒度）+ 各维度 CVR 月环比 vs 月同比分组柱状图。周报的分端/商详商列/电子馆/新客新媒/搜推等图在月报中已全部删除。

## 中文字体（必做）

```python
matplotlib.rcParams['font.family'] = ['PingFang HK', 'STHeiti', 'Arial Unicode MS', 'sans-serif']
matplotlib.rcParams['axes.unicode_minus'] = False
```

macOS 上用 `PingFang HK`，失败回退 `STHeiti`。**绝不用 Windows/Linux 字体名（SimHei / Microsoft YaHei）**。

## charts_manifest.json（产物契约）

```json
{
  "month": "2026-06",
  "charts": [
    {"file": "monthly_trend_25vs26.png", "report_section": "大盘整体", "caption": "...", "render_status": "ok"},
    {"file": "dim_cvr_mom_vs_yoy.png", "report_section": "数据拆解", "caption": "...", "render_status": "ok"}
  ]
}
```

`render_status`：`ok` / `data_missing` / `render_error`。父 agent 只为 `ok` 的图 `docs +media-insert`，其余在文档对应段标 `⚠ 图表生成失败`。

## 失败处理

| 问题 | 处置 |
|---|---|
| CSV 缺失 | 该图条目 `data_missing`，写 manifest |
| 单图渲染异常 | 该图条目 `render_error` + traceback，写 manifest |
| 该图失败 | 退出码 1，但报告流程不因此阻断 |
| 字体回退失败 | 回退 STHeiti / sans-serif，写 manifest warning |

## 不要做的事

- **不要直接调 `lark-cli docs +media-insert`**（父 agent 的事）
- **不要写报告正文 / 不要重跑 SQL / 不要重算指标**
- **不要凭空发明图表类型**（2 张固定图）
- **不要忽略 chart_config.md 视觉规范 / 不要硬编码 Windows 字体**

完成后 stdout 最后一行：`[done] charts rendered N/2, manifest=<path>`

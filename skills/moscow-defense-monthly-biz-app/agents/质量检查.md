# 莫斯科月报-质量检查

## 基础与定位

本 agent 是**闸口型**质量保障节点——**只判定，不修复**，不重新探索，不下业务结论。

核心原则：**`passed = (hard_failures 为空)`** 是铁律。`passed=false` 或 `hard_failures` 非空时编排器必须停在这一步，不进 Step 4。

## 前置阅读

1. **[`../references/monthly-report-requirements.md`](../references/monthly-report-requirements.md)** — 指标口径、合理取值区间、占比加和范围
2. **`analysis_result.json`** — Step 2 产物，复算基准
3. **`../scripts/gen_report_monthly.py`** — 复用 `index_panel` / `metric_with_changes` 做复算，与 Step 2 同一套逻辑

## 校验维度

### 一、数据完整性

| 检查项 | 硬/软 |
|-------|------|
| 2 个 CSV（01_panel/02_daily）都存在且非空 | 硬失败 |
| `01_panel.csv` 含 5 个 `tag_01`（整体 + 4 拆分维度：拆分品类/拆分场景/拆分用户来源/拆分用户资产分层；App 端无「拆分端」）| 硬失败 |
| `01_panel.csv` 每个 `tag_01` 本月/上月/去年同月三切片齐全 | 硬失败（缺去年同月→同比列降级为软失败） |
| 用户分层维度 `wd` 覆盖 z0/z1/z2/z3/z4/z5（Z0-Z5 顺序为预期排序，非异常）| 软失败 |
| `analysis_result.json` 存在，含 `overall`（mom+yoy）+ `dimensions`（4 维度）+ `data_quality` | 硬失败 |

### 二、指标合理性（本月整体行）

| 检查项 | 阈值 | 硬/软 |
|-------|-----|------|
| 净支付转化率 | (0, 0.05) | 硬失败 |
| 商详渗透率 / 商详转化率 / 曝光渗透率 | (0, 1.0) | 硬失败 |
| 任意月环比绝对值 | < 200% | 软失败（标注） |
| 任意同比绝对值 | < 300%（大促月同比波动更大） | 软失败 |
| DAU 整体值 | > 1,000,000 | 软失败 |

### 三、分析结果一致性

- 从 `analysis_result.json` 抽 1-2 维度项（如 dimensions[0].items[0]），用 `metric_with_changes` 从 `01_panel.csv` 复算 cvr / cvr_mom / cvr_yoy
- 偏差 > 0.1ppt → 硬失败；0.05-0.1ppt → 软失败

### 四、跨文件交叉验证（月报特有）

- 用 `02_daily.csv`（维度=整体）本月各日 pay_pv/uv_all 加和，算月均，与 `01_panel.csv` 整体本月行的 dau_日均/单量 比对
- 相对偏差 > 2% → 软失败（分日表与面板口径应吻合，防列错位）

## 校验脚本骨架

```python
import json, csv
from pathlib import Path
import sys
sys.path.insert(0, str(Path.home()/".claude/skills/moscow-defense-monthly-biz-app/scripts"))
from gen_report_monthly import index_panel, metric_with_changes, to_float

MONTH = "${month}"
DIR = Path.home() / f"Downloads/msk_monthly_raw_app/{MONTH}"
hard_failures, soft_failures, warnings = [], [], []
scores = {}  # 各项 score：completeness / plausibility / consistency / cross_check

required = ["01_panel.csv","02_daily.csv"]
for f in required:
    p = DIR / f
    if not p.exists() or p.stat().st_size == 0:
        hard_failures.append({"item": f, "msg": "missing or empty"})

# 二/三/四：按上表逐项（略，实现时补全）
# 用户分层维度 wd 期望覆盖 z0..z5，Z0-Z5 顺序为预期排序，不要当异常

passed = (len(hard_failures) == 0)
result = {"month": MONTH, "passed": passed,
          "hard_failures": hard_failures, "soft_failures": soft_failures,
          "warnings": warnings, "scores": scores}
(DIR/"quality_check.json").write_text(json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8")
print(f"[{'OK' if passed else 'FAIL'}] quality_check passed={passed} hard={len(hard_failures)} soft={len(soft_failures)} warn={len(warnings)}")
```

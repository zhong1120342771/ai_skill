# 月报数据要求 — AI 语料

> 派生自周报要求（https://zhuanspirit.feishu.cn/wiki/TR6CwGhW0iK0SlkBHPzchpzkn1f），时间周期从「周」改为「自然月」，环比口径新增「同比」。

---

## 一、要求

**1.1 时间周期**

月维度，每个自然月（1 号到月末最后一天）为一个周期，每次数据截止至上一个完整自然月。
例：7 月初跑月报，上一个完整月为 6 月（2026-06-01 ~ 2026-06-30）。

- `month`：目标月份，YYYY-MM，默认为「今天所在月 - 1」的上一个完整自然月
- `month_start` / `month_end`：本月首日 / 末日（末日用作 `${outFileSuffix}`）
- `prev_month`：上一个月（月环比的对比基准）
- `yoy_month`：去年同月（同比的对比基准）

**1.2 关注主题**

- 核心关注 dau–净支付pv转化率是否正常
  - 如果涨：涨在什么环节
  - 如果跌：跌在什么环节
- 分维度是否有异常
- 单量和 dau 变化情况的简单总结
- 相比周报，月报额外关注**长周期趋势**（同比 25 vs 26、月度趋势曲线的方向）

**1.3 关注指标**

单量、dau、dau–净支付pv转化率、曝光渗透率、商详到达率、下单率、支付率、商详渗透率、商详转化率

**指标关系**（漏斗路径，与周报一致）：

```
DAU
 └─ 曝光渗透率 → 曝光UV
     └─ 商详到达率 → 商详UV（商详到达率 = 商详UV / 曝光UV）
         └─ 商详渗透率 = 商详UV / DAU
             └─ 下单率 → 下单UV
                 └─ 支付率 → 净支付PV
商详转化率 = 净支付PV / 商详UV
净支付转化率(dau-净支付pv) = 净支付PV / DAU
```

**1.4 拆解维度**

端、品类、场景、用户来源、用户分层（与周报一致，顺序固定）

## 二、环比 / 同比口径（月报核心差异）

月报有两个对比口径，**都由 Python 端基于月度面板 `01_panel.csv` 计算**，不在 SQL 里写窗口：

| 口径 | 定义 | 公式 |
|------|------|------|
| **月环比 (MoM)** | 本月 vs 上月 | `(本月均值 - 上月均值) / 上月均值` |
| **同比 (YoY)** | 本月 vs 去年同月 | `(本月均值 - 去年同月均值) / 去年同月均值` |

- 面板每一行是一个 `(tag_01, wd, 月份)` 的月均绝对值 + 各率。
- 取本月 = `月份 == month`；上月 = `月份 == prev_month`；去年同月 = `月份 == yoy_month`。
- 率类指标（CVR/渗透率等）先各自算出小数，再算环比/同比变化率；不要用「率的字符串」直接相减。
- 绝对值指标（DAU/单量/曝光UV 等）直接用月均绝对值算环比/同比。

**展示分工：**

- **维度 7 列表**：单元格双拼「绝对值（环%｜同%）」——环比与同比并列在同一格，缺失的一侧显示 `-`。
- **同比**：除维度表内嵌外，另体现在 KPI 表（独立「月同比」列）、整体漏斗横表、大盘 25vs26 趋势图、维度同比对比柱状图。
- `analysis_result.json` 里每个指标同时存 `_mom`（月环比）和 `_yoy`（同比）两个字段，话术按需引用。

| 指标 | 月度目标 | 本月均值 | 月环比 | 月同比 |
|------|---------|---------|-------|-------|

- 目标值硬编码业务目标（CVR / DAU / 单量），与周报同一套目标。

## 四、话术结构（每个维度，两段两步）

每个维度的 analysis_text 分**两段**呈现，环比结论与同比结论各自独立，不混在同一句：

**A. 月环比段（本月 vs 上月）** — 两步：
- **第一步：整体趋势** — 该维度各子项净支付转化率本月环比是涨/跌/分化；趋势相同的子项归组合并描述，不逐项罗列。用「上行组中 …(+X%) 提升明显」「下行组 …(-Y%) 下降明显」的说法，**不用"领涨/走弱"**。
- **第二步：驱动环节** — 直接说清各子项（或分组）的净支付转化率主要涨/跌在哪个环节（商详渗透环节 or 商详转化环节），必要时点到子环节（如商详到达、支付率）。判定仍按「商详渗透率 vs 商详转化率 月环比幅度，小者为主驱动」，但**只写结论、不写推导**：**禁用"以…为例""与 CVR 同向且更贴近""为主驱动/为次要项"这类模板腔和百分比堆砌**，按业务话讲，如"笔记本由商详渗透驱动，其余品类由商详转化驱动，电脑办公下降主要受商详转化环节拖累"。
- **不再写"第三步 子环节下钻"整句**——子环节信息若确有必要，并进第二步一句带过即可。

**B. 月同比段（本月 vs 去年同月）** — 单独一段，描述该维度子项净支付转化率同比涨/跌/分化的方向与幅度，用「高于去年组 …」「低于去年组 …」分组。近零项（约 |同比| < 3%）判「持平/基本持平」，不硬塞进高于/低于组。同比缺失（去年无同月数据）的子项显式说明"无去年同月对比"。**禁用"呈环比回升但同比仍低于去年的背离""同比与环比方向一致的子项 N/M 个""7/7 个同向"这类机械统计句**。

话术规则：每条结论带具体数字；趋势相同合并描述；**环比段只讲环比、同比段只讲同比，不要在环比句里夹带同比数字**；**不用"综上所述""总而言之""不仅…而且"等 AI 腔，也不用上面列出的模板腔/机械统计句**；整体从简，能少说就少说，像业务同学写的话。

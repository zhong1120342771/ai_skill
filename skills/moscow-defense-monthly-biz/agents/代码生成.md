# 莫斯科月报-代码生成

## 基础与定位

本 agent 是月报流水线第 1 步的**专家级取数 agent**，专注 Hive SQL / Spark SQL 生产级使用。核心产出是 2 个 CSV，Python 只作执行壳。

与周报的关键差异：**月报用一张月度全维度面板 `01_panel.csv` 替代周报的 01/02/03/04 四段易错窗口 SQL**。面板只出「月均绝对值 + 各率」，环比/同比一律由下游 Python 算，因此**从设计上规避了周报 01_kpi 的 Spark Union NPE**。

## 前置阅读（每次执行前必读）

1. **[`../references/monthly-report-requirements.md`](../references/monthly-report-requirements.md)** — 时间周期定义（自然月）、环比/同比口径
2. **`../scripts/`** 下 2 份 SQL 模板（已业务验证，直接复用，不要重写）：
   - `00_check_partition.sql` — 分区校验
   - `01_panel_monthly.sql` — 月度全维度面板（核心，覆盖 2025-01 至今，含整体+5 维度）
   - `02_daily_metrics.sql` — 分日数据（本月+上月，质检交叉验证用）

## 数据源硬约束

- 归因走 `hdp_zhuanzhuan_tmp_global.tmp_dws_msk_zhibiao_zmt_v2_di`，**禁用** `tmp_dws_msk_zmt_app_v2_di`（同维度名但数差 5–10%）。月报**已统一切到 zhibiao_zmt_v2**。
- 维表 `*_1d_0p` 不带 dt 分区，别加 WHERE dt。
- `${outFileSuffix}` 全部替换为 `month_end`（本月末日，如 `2026-06-30`）。SQL 内部用 `substring(dt,1,7)` 派生月份，用 `date_sub(month_end, N)` 控制回溯窗口。
- **时间上界硬规则（防穿月）**：每段取数 SQL 的 `where` 必须同时有下界和上界 `dt <= '${outFileSuffix}'`。分区常延伸到下一月初（如跑 6 月报时 `dt_max` 已到 7-02），只写 `dt >= ...` 会把下月初分区也捞进来，`substring(dt,1,7)` 多切出一个残缺的下一月桶，污染趋势图与"最新完整月"判定。2 段 SQL 均已内置上界，取数前务必确认 CSV 里最大月份 = `${month}`，不得出现 `${month}` 之后的月份。

## 执行流程

### Step 1-A：分区校验

```bash
python ~/.claude/scripts/oneservice_cli.py \
  --sql "$(cat ~/.claude/skills/moscow-defense-monthly-biz/scripts/00_check_partition.sql)"
```

- `dt_max >= ${month_end}`（本月末日已就绪）→ 进 Step 1-C
- `dt_max < ${month_end}` → 进 Step 1-B（**月报必须等本月末日分区就绪**，否则本月不是完整月）

### Step 1-B：数据刷新（仅在分区未就绪时）

参考飞书文档 https://zhuanspirit.feishu.cn/wiki/HaBhwkuq6ib2VKkpyzXc1QGmnKb 的刷新流程。刷新完重校验，就绪后再继续；仍失败 → 硬失败。

### Step 1-C：并行取数（sub-agent 内部 ThreadPool）

| SQL 文件 | 输出文件 | 备注 |
|---------|---------|------|
| `01_panel_monthly.sql` | `01_panel.csv` | 核心，2025-01 至今全量月度面板 |
| `02_daily_metrics.sql` | `02_daily.csv` | 本月+上月分日 |

执行模板：

```python
import subprocess, concurrent.futures, os, tempfile, time
from pathlib import Path

MONTH = "${month}"          # YYYY-MM
MONTH_END = "${month_end}"  # YYYY-MM-DD 本月末日
SCRIPTS = Path.home() / ".claude/skills/moscow-defense-monthly-biz/scripts"
OUT_DIR = Path.home() / f"Downloads/msk_monthly_raw/{MONTH}"
OUT_DIR.mkdir(parents=True, exist_ok=True)
ONESERVICE = Path.home() / ".claude/scripts/oneservice_cli.py"

SQL_MAP = {
    "01_panel_monthly.sql":          "01_panel.csv",
    "02_daily_metrics.sql":          "02_daily.csv",
}

def run_sql(sql_file, out_file, timeout=1200):
    raw = (SCRIPTS / sql_file).read_text(encoding="utf-8").replace("${outFileSuffix}", MONTH_END)
    with tempfile.NamedTemporaryFile("w", suffix=".sql", delete=False, encoding="utf-8") as tf:
        tf.write(raw); p = tf.name
    out = OUT_DIR / out_file
    t0 = time.time()
    proc = subprocess.run(
        ["python3", str(ONESERVICE), "--file", p, "--output", str(out), "--timeout", str(timeout)],
        capture_output=True, text=True)
    os.unlink(p)
    return sql_file, proc.returncode, time.time()-t0, (proc.stderr or "")[-300:]

with concurrent.futures.ThreadPoolExecutor(max_workers=2) as pool:
    fs = {pool.submit(run_sql, s, o): s for s, o in SQL_MAP.items()}
    failures = []
    for fut in concurrent.futures.as_completed(fs):
        name, rc, dur, tail = fut.result()
        print(f"[{'OK' if rc==0 else 'FAIL'}] {name} rc={rc} dur={dur:.1f}s")
        if rc != 0:
            print(f"      tail: {tail}"); failures.append(name)

if failures:
    raise SystemExit(f"hard failures: {failures}")
```

## 输出规范

- 编码 UTF-8 with BOM；文件名与上表一致，落 `~/Downloads/msk_monthly_raw/${month}/`
- 每个 CSV 落地后跑 `wc -l`，行数为 0 视为失败
- **穿月自检**：含月份列的 CSV（01_panel）落地后校验最大月份 == `${month}`，若出现 `${month}` 之后的月份（如跑 6 月却有 2026-07），说明 SQL 上界失效，视为失败并停
- 最后一行 stdout：`[done] 取数完成，month=${month}，成功 N/2`

## 不要做的事

- **不要重写 SQL 模板**（已业务验证）
- **不要换数据源**（只能 `tmp_dws_msk_zhibiao_zmt_v2_di`）
- **不要硬编码凭证**（只走环境变量 `$ONESERVICE_OA` / `$ONESERVICE_ACCESS_KEY`，星河兜底 `$XINGHE_*`）
- **不要用未完整的当月**——本月末日分区必须就绪，否则不是完整自然月
- **不要静默重试**——失败写 log + stdout

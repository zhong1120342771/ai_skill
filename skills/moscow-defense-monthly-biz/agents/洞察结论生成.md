# 莫斯科月报-洞察结论生成

## 基础与定位

本 agent 是流水线**最后一棒**，产物直接给业务方。整合 5 种能力：报告撰写、XML 渲染、图表生成（内嵌 viz 子 agent）、飞书文档创建、P2P 推送。

与周报的关键差异：报告只保留「一、月数据回顾」单节（「二、重要事项进展」已永久移除），KPI 表列为「指标/月度目标/本月均值/月环比/月同比」（去掉达成率、新增月同比），用户分层维度项按 Z0→Z5 排序。**KPI/漏斗/维度表不手搓，直接调 `gen_report_monthly.py` 从 `01_panel.csv` 构建**。

## 报告结构（精简版：只保留「一、月数据回顾」）

骨架单个 h2：「一、月数据回顾」。**「二、重要事项进展」整节已永久移除**（含搜索流量/商详商列/重点场域/重点人群/供需联动 5 节及其 5 张图）。完整结构见 `references/monthly-report-requirements.md` 第三节。要点：

```
<title>【${month_cn}】莫斯科保卫战月报</title>       ← 例：【2026年6月】
<h2>${month_cn}</h2>                                        ← 月份锚

<h2>一、月数据回顾</h2>
  [图1 monthly_trend_25vs26.png]                            ← 大盘趋势图
  <h3>（一）整体达成度</h3>
    [KPI 5列表：指标/月度目标/本月均值/月环比/月同比]  ← build_kpi_table(idx, month)
  <h3>（二）数据拆解</h3>
    [文字 1-2 句：本月 CVR/DAU/单量 + 月环比 + 同比 + 主驱动一句话]
    [整体漏斗 12 列横表]                                  ← build_funnel_table(idx, month)
    [图2 dim_cvr_mom_vs_yoy.png]                          ← 各维度 CVR 环比vs同比对比柱状
    <h4>1、端</h4>   [analysis_text 分环比段+同比段][7 列表 build_dim_table 双拼环比｜同比][<p>流量&单量结构</p>][6 列构成表 build_struct_table]
    <h4>2、品类</h4> [analysis_text][7 列表]              ← 无结构表
    <h4>3、场景</h4> [analysis_text][7 列表][<p>流量&单量结构</p>][6 列构成表 use_exposure=True]
    <h4>4、用户来源</h4> [analysis_text][7 列表][<p>流量&单量结构</p>][6 列构成表]
    <h4>5、用户分层</h4> [analysis_text][7 列表]          ← 维度项按 Z0→Z5 排序（z0/z1/.../z5），无结构表

（报告到此结束，不再有「二、重要事项进展」及后续任何 h2）
```

### 强制砍掉的元素

顶部 callout 概览块、「漏斗口径」独立 h2、独立「KPI 达成率」h2（并入整体达成度）、「📐 构成…」灰色 callout、「⚠ 数据待补」独立段、末尾 `<hr/>`、**以及整个「二、重要事项进展」模块**（搜索流量/商详商列/重点场域/重点人群/供需联动，连同 supp1–4 数据与 5 张图一并移除）。

## 关键约束

### KPI/漏斗/维度表直接调 gen_report_monthly

```python
import sys, csv
from pathlib import Path
sys.path.insert(0, str(Path.home()/".claude/skills/moscow-defense-monthly-biz/scripts"))
from gen_report_monthly import (index_panel, build_kpi_table, build_funnel_table,
                                 build_dim_table, build_struct_table, month_cn)
MONTH = "${month}"
DIR = Path.home()/f"Downloads/msk_monthly_raw/{MONTH}"
idx = index_panel(list(csv.DictReader(open(DIR/'01_panel.csv', encoding='utf-8-sig'))))

kpi_xml    = build_kpi_table(idx, MONTH)                          # 5 列：指标/月度目标/本月均值/月环比/月同比
funnel_xml = build_funnel_table(idx, MONTH)
duan_tbl   = build_dim_table(idx, '端', MONTH)
duan_struct= build_struct_table(idx, '端', MONTH)                 # 端：DAU 口径
scene_struct = build_struct_table(idx, '场景', MONTH, use_exposure=True)  # 场景：曝光UV 渗透率口径
# 用户分层表：build_dim_table 内部已按 Z0→Z5 排序，无需额外处理
fenceng_tbl = build_dim_table(idx, '用户分层', MONTH)
```

- KPI 目标值硬编码在 `gen_report_monthly.KPI_TARGETS`（CVR=1.26% / DAU=450万 / 单量=56674），与周报同一套。
- KPI 表已**去掉「达成率」列**，改为「本月均值 + 月环比 + 月同比」；同比=本月 vs 去年同月。
- 维度表单元格双拼「绝对值（环%｜同%）」（`fmt_cell_dual` 渲染），环比同比并列，缺失一侧显示 `-`。
- 用户分层维度项固定 Z0→Z5 顺序（由 `_dim_items` 内部排序保证）。
- 占比加和检查：端/用户来源 DAU 占比 95-105%，场景曝光UV渗透率 150-220%（>100% 正确）。

### 话术规则

- 每个维度 analysis_text 分**两段**：先「月环比段」（两步：整体趋势→驱动环节，不写"第三步子环节下钻"整句），再「月同比段」（本月 vs 去年同月，用高于/低于去年组分组，近零判持平）。**环比段只讲环比、同比段只讲同比，不混句。**
- **禁用模板腔/机械统计句**：环比段不用"以…为例""与 CVR 同向且更贴近""为主驱动/为次要项"、不用"领涨/走弱"；同比段不用"呈环比回升但同比仍低于去年的背离""N/M 个同向""7/7 个同向"。按业务话讲、能少说就少说。
- 每个结论带具体数字（如 `环+5.35%`、`同-2.10%`、`CVR=1.260%`）；同比缺失的子项显式说明"无去年同月对比"。
- quality_check 有 warn/soft 时，对应条目末尾标 `⚠ 数据待复核`
- **不用"综上所述""总而言之""不仅…而且"等 AI 腔**；趋势相同的维度项合并描述

```bash

lark-cli im +messages-send \
  --user-id ou_5e572adca6deef8ef21c3b18dfade573 \
  --msg-type text \
  --content '{"text": "📊 莫斯科保卫战月报（'${month}'）已生成\n\n核心指标：CVR='${cvr}'%（月环比'${cvr_mom}'%，同比'${cvr_yoy}'%），DAU='${dau}'万（'${dau_mom}'%），单量='${pay_pv}'（'${pay_pv_mom}'%）\n\n完整文档 👉 '${DOC_URL}'"}' \

```

消息格式：第一行标题+月份，第二行核心指标（CVR+DAU+单量，CVR 带月环比+同比），第三行裸 URL。

## 失败处理

- **飞书文档创建失败** → 停止，不发 IM，**不回退发本地路径**
- **文档成功但 IM 失败** → 仅重推 IM，复用 `doc_url`，**不重建文档**
- **不得把推送目标改为群聊**，除非编排器显式传入 group_chat_id

## 不要做的事

- **不要重算指标**（KPI/漏斗/维度表由 gen_report_monthly 从面板构建；数值话术来自 analysis_result.json）
- **不要无视 quality_check warn**（必须带 ⚠）
- **不要在正文粘 SQL / 不要把 P2P 改群聊 / 不要用旧 XML 标签 / 不要硬编码 doc_token 给推送脚本**

完成后 stdout 最后一行：`[done] doc_url=<URL> p2p=ok`

# 莫斯科周报-数据可视化

## 🚨 默认执行路径：直接跑固化脚本（不要重写代码）

**99% 的情况下你只需要做一件事**：

```bash
WEEK_END=${week_end} python3 ~/.claude/skills/moscow-defense-weekly-biz-app/scripts/render_charts.py
```

跑完检查 `~/Downloads/msk_weekly_raw_app/${week_end}/charts/charts_manifest.json` 存在即可返回父 agent。**不要重写 6 张图的渲染代码**——它已固化、已用户验收（基线 docx `CgBUdPbUTovAOYxO7NoceE62n0g`），重写只会引入回归。

**仅在下列情况下才修改 `scripts/render_charts.py`**：
- 数据口径变更需要新指标 / 新分组
- CSV 字段名/列结构发生变化
- 飞书 sheet `WrB7sjN0VhvIgjttMn2cHuALnlf` 不再可用
- 用户在本轮对话中明确要求改视觉

修改时必须保持：5 色体系、`force_week_ticks`、`annotate_group` 三件套不变，输出仍是 6 张同名 PNG + `charts_manifest.json`。

## 基础与定位

本 agent 是**洞察结论生成 agent 的内嵌子 agent**，整合 1 种能力：

- **图表生成**：把 Step 1 的原始 CSV / Step 2 的 `analysis_result.json` 翻成符合 `references/chart_config.md` 视觉规范的 PNG 图

**严格的边界：**

- **不写飞书文档**——是父 agent（洞察结论生成）的事
- **不推送 IM**——是父 agent 的事
- **不改数字**——数据来自 Step 1 CSV + Step 2 JSON，不重新计算指标
- **不在主流水线 4 步内**——本 agent 由洞察结论生成 agent 在写文档前内嵌调起，主编排器看不到本步

### 三阶段方法论

**阶段一：数据装载**
- 按 `inputs` 列表读 CSV / JSON
- `encoding='utf-8-sig'` 防 BOM
- 字段量级校验：DAU 百万级 / 单量万级 / CVR 0.1%–1.5%（详见 `chart_config.md` 数据列校验段）

**阶段二：图表规划**
- 6 张固定图（1 张大盘 + 5 张分业务），对应报告 6 个嵌图位
- 每张图选合适的图表类型与版式（单图 / 1×2 / 2×2 / 7-panel GridSpec）
- 用统一颜色体系（5 色见 `chart_config.md`）

**阶段三：批量渲染 + 清单落盘**
- 每张图独立函数渲染，失败不要让其他图连坐
- 渲染完写 `charts_manifest.json`，告诉父 agent 每张图要插在报告哪一段

```python
def style_ax(ax):
    """每张子图都调一次：去掉边框 + 横向网格 + 隐藏刻度线"""

    for x, y in zip(xs, ys):
```

## 工程规范（基线第 3 版踩坑后的硬约束）

### 横轴 tick 完整性

matplotlib 在 datetime 轴上会自动稀疏 tick，**8 周数据时最右一周（含 week_end）经常被略掉**。所有周维度图必须：

```python
def force_week_ticks(ax, weeks):
    uniq = sorted({d for d in weeks if d is not None})
    if not uniq:
        return
    ax.set_xticks(uniq)
    ax.set_xticklabels([d.strftime('%m-%d') for d in uniq], fontsize=8)
    # 两端各 5% 时间 margin，防边缘 clip
    span = (uniq[-1] - uniq[0]).days if len(uniq) > 1 else 1
    pad = max(1, span * 0.05)
    ax.set_xlim(uniq[0] - pd.Timedelta(days=pad), uniq[-1] + pd.Timedelta(days=pad))
```

### 数据标签避让重叠（多线必用）

同一 x 处多条线的标注必须按 y 升序错位避让，**不要为每条线写死单一 offset**：

```python
def annotate_group(ax, series, pct=False, fontsize=7.5):
    """series: List[(xs, ys, color)]"""
    from collections import defaultdict
    bucket = defaultdict(list)
    for li, (xs, ys, color) in enumerate(series):
        for x, y in zip(xs, ys):
            if y is None or (isinstance(y, float) and np.isnan(y)):
                continue
            bucket[x].append((y, color, li))
    for x, items in bucket.items():
        items.sort(key=lambda t: t[0])
        n = len(items)
        if n == 1:
            y, color, _ = items[0]
            txt = f"{y*100:.2f}%" if pct else (f"{int(round(y)):,}" if abs(y)>=100 else f"{y:.2f}")
            ax.annotate(txt, (x, y), textcoords='offset points', xytext=(0, 8),
                        ha='center', va='bottom', fontsize=fontsize, color=color)
            continue
        step = 13
        mid = (n - 1) / 2.0
        offsets = []
        for i in range(n):
            if i >= mid:
                offsets.append((0, 8 + step * (i - int(mid)), 'bottom'))
            else:
                rank_down = (int(mid) - i) if (n % 2) else (int(mid) - i + 1)
                offsets.append((0, -10 - step * (rank_down - 1), 'top'))
        for (y, color, _), (dx, dy, va) in zip(items, offsets):
            txt = f"{y*100:.2f}%" if pct else (f"{int(round(y)):,}" if abs(y)>=100 else f"{y:.2f}")
            ax.annotate(txt, (x, y), textcoords='offset points', xytext=(dx, dy),
                        ha='center', va=va, fontsize=fontsize, color=color)
```

每个 render 函数：先 plot 收集 `series=[(xs,ys,color), ...]`，最后一并调 `annotate_group(ax, series, pct=...)`。

```python
def safe(name, fn, section, caption):
    try:
        out = fn()
        manifest['charts'].append({
            "file": out.name, "report_section": section,
            "caption": caption, "render_status": "ok"})
    except Exception as e:
        import traceback; traceback.print_exc()
        manifest['charts'].append({
            "file": f"{name}.png", "report_section": section,
            "caption": caption, "render_status": "render_error",
            "error": str(e)})
```

## 失败处理

| 问题 | 处置 |
|---|---|
| 单 CSV 缺失 | manifest 对应条目 `render_status="data_missing"`，**不阻断其他图** |
| 单图渲染异常 | manifest 对应条目 `render_status="render_error"`，捕获 traceback 写 stdout |
| 全部 6 张图都失败 | 退出码 1，父 agent 接到失败信号——但**报告流程不应因此阻断**，父 agent 在文档对应段标 `⚠ 图表生成失败` 后继续 |
| 字体回退失败（macOS 没 PingFang HK） | 自动回退到 `STHeiti`；都不行则 sans-serif（图表可能中文缺字，写入 manifest warning） |

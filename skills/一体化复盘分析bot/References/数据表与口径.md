# 数据表与口径

复盘用到的全部底表、字段、口径，以及复盘特有的取数查询。日频取数 SQL 已镜像到 `scripts/sql/`（来源为日报 bot）。

## 一、核心底表速查

| 指标 | 源表 | schema | 关键字段 | 口径 |
|---|---|---|---|---|
| 同城订单量/占比 | `dws_yth_core_xianshang_layer01_zmt_v1_di` | `hdp_zhuanzhuan_tmp_global` | city, if_bd, ct, dt | 同城订单量=if_bd=1 的 ct 汇总；占比=同城/总订单 |
| 同城订单**仓/店拆分** | `dws_yth_core_xianshang_layer01_zmt_v1_0722_di` | `hdp_zhuanzhuan_tmp_global` | **md_type**, city, if_bd/local, total, dt | 带 md_type（仓库/门店），门店可再拆小店/pro店 |
| 小时达订单量 | `dws_yth_core_xsd_layer01_zmt_v1_0723_di`（旧 `..._v1_di` 弃用） | `hdp_zhuanzhuan_dw_global` | city, **abgroup**, jzf_pv, dt | jzf_pv 汇总；0723 表 abgroup=仓库订单/小店/pro/其他（门店已拆 pro/小店，见下） |
| 线下线索/转化 | `dws_yth_xs01_yykj_zmt_v1_di`(预约看件) + `dws_yth_xs02_mdkh_zmt_v1_di`(门店看货) | `hdp_zhuanzhuan_dw_global` | tag, xs_uv, pay_uv, dt | 线索量=xs_uv 汇总；转化量=pay_uv 汇总 |
| 同售单量/动销率 | `dws_yth_ts_kc_ord_zmt_di` | `hdp_zhuanzhuan_dw_global` | city, type_md, kc_ts, pay_pv, dt | 同售单量=pay_pv；动销率=pay_pv/kc_ts（kc_ts=同售库存） |

所有表都有 `dt` 分区（格式 yyyy-MM-dd）；复盘按周期 `dt between 起 and 止` 取全周期明细，不加 t-1。

## 二、字段口径与踩坑（务必先查 distinct 实际取值）

### abgroup 字段有两副面孔（血泪）
- **城市表**（xianshang）里如果出现 abgroup：标签**过时**，只把郑蓉标一体化、其余标非一体化，与实际相反 → 分层**弃用 abgroup，按城市名重打标**。
- **小时达表**（xsd）里 abgroup 实际取值是仓/店标记，字段注释"是否一体化城市"**是错的**。v1_di 表为 仓库订单/店铺订单/其他；**0723 表更细**，把店铺订单再拆成 小店/pro，取值 = 仓库订单/小店/pro/其他，做门店拆 pro/小店时用 0723。日报 bot 的 `04_xiaoshida.sql` 已把它 alias 成"仓店类型"。
- 通用铁律：**任何维度字段先 `SELECT col, count(*) GROUP BY col` 看真实取值，不信注释**。

### if_bd
同城订单标记，1=本地，0=否。同城订单量 = `sum(case when if_bd=1 then ct else 0 end)`。

### type_md
门店类型，复盘只取 `('小店','pro店')`。同售门店试点仅郑州&成都。

### md_type（0722 拆分表）
仓库 / 门店；门店侧再按 type_md 或子标记拆小店/pro店。仓/店拆分只能用这张 0722 版表（主 v1 表无此维度）。

## 三、复盘特有取数（日报没有的）

### 3.1 同城订单仓/店拆分（0722 表）
```sql
SELECT dt, md_type, city,
       sum(total_ct) total, sum(local_ct) local
FROM hdp_zhuanzhuan_tmp_global.dws_yth_core_xianshang_layer01_zmt_v1_0722_di
WHERE dt BETWEEN '<起>' AND '<止>'
GROUP BY dt, md_type, city;
```
落 `data_storage/yiti_xianshang_cangdian_<周期>.csv`（列 dt,md_type,city,total,local）。分析时 `~city.isin(['重庆市','西安市'])` 取全一体化口径。
**对齐**：0722 表与主 v1 表某些月合计差几十单，各档需按主口径月总数**等比缩放**对齐（fig10 脚本已实现）。

### 3.2 小时达仓/店拆分 + 门店再拆 pro/小店 + 整体
**用 0723 表 `dws_yth_core_xsd_layer01_zmt_v1_0723_di`**（比 v1_di 更细：abgroup 取值 = 仓库订单/小店/pro/其他，即把原「店铺订单」拆成小店+pro）。0723 整体与 v1_di 整体一致（H1 均为 20→386），但仓/店内部分配略有差异（v1_di：仓库 345/店铺 37；0723：仓库 352/门店 31），以 0723 为准。
```sql
-- 拆分（各 tier pv）: abgroup ∈ {仓库订单, 小店, pro, 其他}
SELECT substr(dt,1,7) m, abgroup, sum(jzf_pv) pv
FROM hdp_zhuanzhuan_dw_global.dws_yth_core_xsd_layer01_zmt_v1_0723_di
WHERE dt BETWEEN '<起>' AND '<止>' GROUP BY substr(dt,1,7), abgroup;
-- 整体（单一月度天数，作为对齐基准）
SELECT substr(dt,1,7) m, count(distinct dt) nd_month, sum(jzf_pv) tot_pv
FROM hdp_zhuanzhuan_dw_global.dws_yth_core_xsd_layer01_zmt_v1_0723_di
WHERE dt BETWEEN '<起>' AND '<止>' GROUP BY substr(dt,1,7);
```
**对齐**：各档日均一律 `tier_pv / nd_month`（共用整体月度天数），Σ 严格等于 `tot_pv/nd_month`。**不要**用各 tier 自己的 nd（稀疏的"其他"会被放大）。fig12（仓库/门店/其他，门店=小店+pro）与 fig13（门店内 pro vs 小店）脚本已按此实现。旧 v1_di 表只到店铺订单粒度、无 pro/小店拆分，已弃用。

### 3.3 pro店同售 按城市拆解（不再用双城/非双城）
```sql
-- 按城市逐个拆; 日均对齐见下方对齐说明
SELECT substr(dt,1,7) m, city, count(distinct dt) nd,
       sum(pay_pv) pay_pv, sum(kc_ts) kc_ts
FROM hdp_zhuanzhuan_dw_global.dws_yth_ts_kc_ord_zmt_di
WHERE dt BETWEEN '<起>' AND '<止>' AND type_md='pro店'
GROUP BY substr(dt,1,7), city;
-- 整体月度天数(作对齐基准)
SELECT substr(dt,1,7) m, count(distinct dt) nd_month,
       sum(pay_pv) tot_pv, sum(kc_ts) tot_kc
FROM hdp_zhuanzhuan_dw_global.dws_yth_ts_kc_ord_zmt_di
WHERE dt BETWEEN '<起>' AND '<止>' AND type_md='pro店'
GROUP BY substr(dt,1,7);
```
**对齐**：各城日均 = `city_pay_pv / nd_month`（共用整体月度天数，同小时达坑1口径），Σ 严格等于整体。H1 出现的城市：郑州（1 月起唯一）、东莞（4 月上线）、成都（5 月起量）。动销率各城单算 `pay_pv/kc_ts`。fig9 = `fig9_pro_volume_by_city.py`（按城市堆叠），旧全口径 vs 双城版弃用。

### 3.4 小店同售城市三档 DiD
见 `scripts/sql/05_tongshou_dongxiao_by_yiti_city.sql`：对照(重庆&西安)/覆盖(郑州&成都)/其他三档，字段 kc_ts、pay_pv，保证三档之和=小店同售主口径。

### 3.5 2025 同比基线（占比 + 绝对量都能同比）
xianshang 表存有 2025 分区，占比和绝对量都可拉 2025 H1 同月做同比。
```sql
-- 按城市拉 2025+2026 的同城量与总量, 一次算量同比+占比同比
SELECT substr(dt,1,7) m, city,
       count(distinct dt) nd,
       sum(case when if_bd=1 then ct else 0 end) tc_ord,  -- 同城订单量
       sum(ct) tot                                          -- 总订单量(占比分母)
FROM hdp_zhuanzhuan_tmp_global.dws_yth_core_xianshang_layer01_zmt_v1_di
WHERE substr(dt,1,4) IN ('2025','2026') AND cast(substr(dt,6,2) as int) BETWEEN 1 AND 6
GROUP BY substr(dt,1,7), city;
```
**踩坑**：2025 分区 city 字段有脏值（"成都"/"成都市"、"深圳"/"深圳市" 并存），归一时双城集合要同时含带"市"和不带"市"两种写法，否则双城量会漏。
- **量同比**（fig15）：双城日均 25 年 197→284(+44.0%) vs 26 年 232→423(+82.5%)；全一体化 25 年 744→1016(+36.6%) vs 26 年 918→1501(+63.4%)。去年靠大盘本就在涨，今年增幅约两倍，超出去年的净增（双城≈+38pp、全一体化≈+27pp）方向与 DiD(+6.78pp) 一致。6 月绝对量同比双城 +48.7%、全一体化 +47.8%。
- **占比同比**（fig2）：试点双城 25 年 18.77%→20.04%(平) vs 26 年 +7.67pp 爬坡。全一体化占比分母是全国总订单、量级本就低（2-4%），25 年 2.25%→2.87%、26 年 3.04%→4.00%，主看试点口径。

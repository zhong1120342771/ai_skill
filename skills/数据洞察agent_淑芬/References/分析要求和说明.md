# 分析要求和说明

> 来源：飞书文档 https://zhuanspirit.feishu.cn/wiki/Hz97wGlCdiqzDHknh7XcuEuQnwb

## 一、业务关心重点

分析优先覆盖这些问题：

1. 首页整体有没有被有效使用？
2. 首页模块结构是否影响用户行为？
3. 用户实际看到了哪些首页内容？
4. 用户在首页内产生了哪些行为？
5. 不同用户分层在首页上的响应是否不同？
6. 是否存在首页整体平稳但内部结构迁移？
7. 是否存在高曝光但低价值的位置或内容？
8. 是否存在某模块提升但挤压其他模块的情况？
9. 当前数据是否足够支持机会判断？
10. 哪些结论必须等真实数据或实验验证？

## 二、可以重点关注的指标方向

- 首页每个模块（整个页面、场馆 tab 的点击、搜索框、大促三切分、金刚位（整体-坑位）、回收模块、新人条、栏目区、feed 流等）的利用效率怎么样，曝光点击等，有没有什么机会点
- 不同类型的用户表现如何：分用户来源、分用户资产可以简单分为 新用户（z0）、浅用户（z1-z3）、有交易行为的老用户（z4-z5）

#### 场馆 TAB

提供 4 个场馆 TAB 切换，从左到右依次为"推荐"、"奢品馆"、"电子城"、"兴趣 keng"（兴趣坑）。俗称：一级 TAB。

| 功能描述 | 接口字段 |
|---|---|
| 默认 4 个 TAB，支持服务端控制数量 | 接口：/api/zzlogic/cbchomepagetabinfo；一级TAB列表 firstTab 由接口下发，数量不固定。✅服务端可配 |
| 每个 TAB 三部分组成：图标、名称、角标 | 单个 TAB 信息 tabInfo（含图标、名称图、角标 rightBadgeUrl）。✅服务端可配 |
| 图标是图片，支持动图 | 选中图标 selectUpImg、非选中图标 unSelectUpImg。✅服务端可配 |
| 切换场馆 TAB 时，新选中的 TAB 播放图标动画 | 动画效果客户端内置，触发时机为切换选中态。⚙️客户端策略 |
| 名称是图片，有选中态、非选中态 | 选中名称图 titleSelectImg(含宽 titleSelectImgWidth/高 titleSelectImgHeight)、非选中 titleUnSelectImg。✅服务端可配 |
| 角标支持文字、图片两种样式 | 角标 rightBadgeUrl，uiType=1 文字、uiType=2 图片。✅服务端可配 |
| 文字角标支持多个循环轮播 | 文字列表 textList(多条轮播)、文字色 textColor、背景色 backColor。✅服务端可配 |
| 图片角标尺寸固定 | 图片 badgePic，尺寸客户端固定。⚙️客户端策略 |
| 角标优先级，服务端下发，数字越小越高优。接口返回高优的，客户端优先展示，替换已有的。如果优先级相同，使用 TAB 索引小的 | 优先级 priority(默认999)；客户端按优先级择一展示。✅服务端可配 |
| 角标支持 2 种展示策略：1) 客户端控制，默认只展示一个自然日。逾期或者用户点击，隐藏不再展示；2) 综合控制。服务端下发展示时长。在时长内均展示该角标。超过时长并且刷新接口时 或者 点击角标后，角标隐藏。如有新配置，按新配置展示 | 策略字段 strategy：NATURE_CLICK=客户端控制(自然日)、SHOW_TIME_CLICK=综合控制；综合控制展示时长 noClickShowTime(秒)。✅服务端可配 |
| 角标先判断优先级，再判断展示策略 | 决策顺序客户端固定。⚙️客户端策略 |
| 点击角标可联动选中指定二级 TAB / 触发回调 | selectSecondTabId 指定点击后选中的二级TAB；bizType=actionBadge 标记活动角标；callback 回调参数。✅服务端可配 |

##### 商卡 Feed 流

> **模块口径(2026-07-15)**：Feed 拆成两个独立核心模块，不再合并统计——
> - **商卡feed流(section 108，权威名 feed商品卡片)**：双列瀑布流商品卡本体，是内容承接主体。
> - **feed轮播图(section 109，权威名 feed轮播图)**：Feed 第二位固定运营位，多图轮播、点击跳转落地页，是**可点运营位**。
>
> 两者点击效率差异大（108 属高 CTR 内容位，109 运营位 CTR 显著偏低），合并会把 109 的低点击信号稀释进 108、永远暴露不出来，故 `section-to-module.json` 从 2026-07-15 起把 109 单列为「feed轮播图」模块。

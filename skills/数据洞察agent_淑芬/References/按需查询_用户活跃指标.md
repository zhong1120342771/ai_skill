## 一、需求

查转转各平台（分端）的活跃用户规模与留存，指标：

| 指标 | 单位 | 说明 |
|---|---|---|
| 用户注册数量 | 万人 | **本表算不了全站累计注册**（见下），当次跳过 |
| MAU 活跃用户 | 万人 | 近30天去重活跃用户 |
| DAU 活跃用户 | 万人 | 取数日当天去重活跃用户 |
| 用户30日留存率 | % | 活跃留存，**两个口径**（时点/累计，见下），非注册后第N日留存 |

## 二、数据源与口径真源

**表**：`hdp_zhuanzhuan_dm_global.dm_oper_user_layer_dtl_inc_1d`（DAU用户分层明细表）

关键字段（实测确认，非推断）：
- `token`：唯一用户标识（去重口径都用它，不用 uid）。
- `dt`：分区，yyyy-MM-dd。**每个 dt 分区 = 当天活跃用户快照**——已验证单分区内 `active_date` 恒等于 `dt`。所以 DAU 直接按 `dt` 取，MAU 跨 30 个分区 distinct token。
- `terminal_name`：分端，取值 `转转APP` / `转转小程序` / `找靓机`。
- `regist_time`：注册时间（yyyy-MM-dd HH:mm:ss）。
- `active_date`：活跃日期（= dt）。
- 分区可用范围实测约近 40 天连续（如 2026-06-06 ~ 07-15），t-1 通常就绪。

**引擎**：星河 Hive，`sql_engine=5`；ORDER BY 必须带 `limit`（strict mode）。

### 口径定义（2026-07-16 钟梦婷确认）
- **DAU** = 取数日（默认 t-1）当天 distinct token，分端。
- **MAU** = 近30天（取数日-29 ~ 取数日）distinct token，分端。
- **30日活跃留存率** = 以（近30天起始日 - 1 天）当天活跃用户为基准（base_uv），分端。
  **两个口径**（2026-07-16 董亚坤补充要求）：
  - **口径1（间隔第30天 / 时点留存）**：base 用户恰好在第30天当天（= 取数日）再活跃的占比。
    只看那一个点，通常远低于口径2。
  - **口径2（后续30天内 / 累计留存）**：base 用户在近30天窗口内任意一天再活跃的占比。
  两者均为**活跃口径**（回访型留存），不是「注册后第 N 日留存」——本表只有 `active_date`，做不了严格的注册后第N日。
- **注册数量**：本表是**活跃用户明细**（只含活跃过的 token），**算不了全站累计注册**。
  如需注册量，必须换注册底表；当次按钟梦婷指示跳过。

# 数据洞察agent_淑芬 Token 预算分配图

对淑芬这条流水线的每条指令消息做了一次 token 估算。先说最关键的一点：淑芬不是「一个上下文吃掉一份预算」，而是「1 个编排器主上下文 + 6 个相互隔离的子 agent 上下文」。所以预算是分散的，全目录朴素合计约 9.6 万 token，但任一时刻真正的约束只是当前那一个上下文，不能把 6 份定义加在一起看。

估算口径：中文字符按 0.9 token/char、ASCII（英文/代码/符号）按 0.28 token/char 分档换算，属于量级估计，不是精确计费。

## 三层结构

```
全局固定层（每个上下文都背，卸不掉）
CLAUDE.md 1847 + MEMORY.md 1109 ≈ 2,956 tok
        │（叠加进下面每一个上下文）
        ├──────────────┬─────────────────────────┐
        ▼              ▼                          ▼
编排器主上下文        6 个子 agent（各自独立上下文，互不叠加）
SKILL.md ≈7,835     代码生成 5026 / app体验 5360 / 数据分析 9609
（常驻主线程）        质检 4975 / 洞察结论 12512 / 机会计算器 11953
+ 6 次调度状态(极小)
```

## 固定开销 / 动态开销 / 可压缩

| 类别 | 内容 | 估算 token | 说明 |
|---|---|---|---|
| 固定 | CLAUDE.md + MEMORY.md | 2,956 | 每个上下文都背，除非精简全局配置 |
| 固定 | SKILL.md 编排器 | 7,835 | 常驻主线程，是编排器的宪法 |
| 固定 | 6 个子 agent 定义 | 49,435 合计 | 分 6 个隔离上下文，单次只加载 1 份 |
| 动态 | 上游落盘产物摘要(json/md) | 每步 2~15k | 随当天模块数、假设数、机会点数浮动 |
| 动态 | CSV 原始数据 | 约 0 入上下文 | 70MB 曝光表由 pandas 处理，只回流摘要 |
| 可压缩 | SKILL.md 偏胖 | 可省 ~2,500 | 红线速查、路径大小写告警有重复 |
| 可压缩 | 洞察结论生成、机会计算器 | 各可省 ~3,000 | 两份定义把 References 内容抄了一遍 |
| 可压缩 | References 被多步重复读 | 视调用 | output-schemas 6,598，多个机器产物步骤都读 |

## 单上下文实际峰值

真正决定会不会爆预算的，是当前那一个子 agent 的上下文，不是全目录合计。

- Step5 机会计算器峰值 ≈ 全局 2,956 + 定义 11,953 + Step4 报告 ~6,000 + exploration/hypotheses/quality 摘要 ~5,000 + dau_full/conv_aov 小量 ≈ **26,000 tok（全链最贵）**
- Step2/Step3 中段 ≈ 全局 2,956 + 定义 + CSV 摘要 ≈ 12,000~18,000 tok
- 编排器主线程 ≈ 全局 2,956 + SKILL 7,835 + 调度状态 ≈ 11,000 tok（很稳）

## 三个可压缩抓手

1. 两份重定义抄了 References：`洞察结论生成.md`(12,512) 和 `机会计算器.md`(11,953) 里把 output-schemas、分析口径重述了一遍。改成「按 References/output-schemas.md 执行，不复述」，两份各省约 3,000 token，合计 ~6,000。
2. SKILL.md 有重复告警：大小写硬约束、红线速查在正文和表格里各出现一次。收敛后编排器主上下文能从 7,835 降到 ~5,300。
3. 不该动的别动：CSV 大表已经是最优，不进上下文；`Scripts/` 的 Python（合计 19,566）是执行体，也不进 prompt。这两块占朴素合计一大半，但对真实预算贡献接近零，不是压缩目标。同理，`_bundled_deps/`（迁移用的依赖备份，约 124K）是给目标机解压还原用的物料，任何子 agent 都不读它，对运行时 token 预算零贡献。

## 结论

淑芬的架构本身就省 token：靠子 agent 隔离把 4.9 万的定义拆成 6 份错峰加载，靠「CSV 走 pandas 不走上下文」避开了几百 MB 数据。要再挤，只有那两份重定义和 SKILL.md 的重复告警值得动，能省约 1.2 万 token，且不伤功能。

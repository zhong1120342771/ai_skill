# 转转 App 首页体验报告

- 运行 ID：homepage_20260701_113935
- 设备：Android 模拟器（1080×2400，3G 网络，红米/一加/OPPO 机型标识轮换）
- 应用包名：com.wuba.zhuanzhuan
- 视角：全新用户（未登录）首启动 → 首页浏览

## 一、体验路径概览

| 步骤 | 界面 | 关键动作 | 结果 |
|------|------|----------|------|
| 1 | 冷启动 | 打开 App | 进入引导问卷（WebView） |
| 2 | 新人问卷 | 「你身边是否有不用的【旧手机/旧平板/鞋…】」有/没有 | 单击可推进，但品类循环出现（手机→平板→鞋→…） |
| 3 | 问卷退出 | 「跳过」未生效，改用系统返回键 | 成功退出到主页 |
| 4 | 兼容性弹窗 | 「检测到当前设备存在兼容性风险」继续使用/立即退出 | 点「继续使用」进入首页 |
| 5 | 首页推荐流 | 顶部搜索/分类金刚区 + 瀑布流商品 | 内容丰富，正常加载 |
| 6 | 商品详情 | 点击瀑布流卡片 | WebView 详情页加载，但首屏白屏延迟明显 |

## 二、正向体验

- **首页信息密度高、结构清晰**：顶部搜索框（带热词轮播）、推荐/奢品馆/电子城/兴趣圈 Tab、两行金刚区（手机、平板、笔记本、腕表、骑行、大牌包袋、台球杆、摄影摄像、新能源车、游戏交易、首饰配饰…），下方「转转回收」入口 + 新人礼包，再接双列瀑布流。层级明确，符合二手电商用户预期。
- **商品卡信息完整**：售价、满减、「同款销量30万+/1万+」「在仓直发」「快惠选」等信任与促销标签齐全，转化钩子清楚。
- **瀑布流内容深、样式多元**：普通商品卡、转转榜单（耳机排行榜）、限时秒杀（立减¥90）、新人专享（已减¥170）等模块穿插，浏览不单调。
- **新人激励前置**：¥7800 新人礼包 banner + 「新人专享」商品标签，对拉新有明确牵引。

## 三、体验问题（按严重度）

### P0 — 阻断/劝退级
1. **新人问卷是强制前置漏斗，且「跳过」不生效**
   - 全新用户首启动直接落到 WebView 问卷，而非首页。
   - 「跳过」点击无响应，问卷品类还会循环（手机→平板→鞋…），给人「答不完」的错觉。
   - 最终只能靠系统返回键逃出，普通用户很可能在此流失。
   - 建议：问卷弱化为可跳过的浮层/首页内模块；确保「跳过」热区可点；限定问卷长度并有明确「完成」出口。

2. **兼容性风险弹窗吓退**
   - 「检测到当前设备存在兼容性风险」+「立即退出」按钮，措辞消极、退出按钮高亮（蓝色），对真实低端机用户是明显劝退。
   - 建议：非致命兼容问题不应以「风险 + 立即退出」呈现；弱化文案，默认「继续使用」，避免误导用户退出。

### P1 — 影响核心转化
3. **商品详情页首屏白屏**
   - 点击卡片后详情页（WebContainerActivity）出现明显白屏，内容（验机报告、质保、7天无理由、加购物车）在 UI 树中已存在但可视渲染延迟数秒。
   - 3G 环境下 WebView 详情页体验尤其差，直接影响「点击→查看→下单」链路。
   - 建议：详情页首屏骨架屏/预渲染；核心信息原生化，降低 WebView 依赖。

### P2 — 体验打磨
4. **底部登录横条常驻遮挡**
   - 「登录转转，开启省钱新生活 / 立即登录」横条常驻在瀑布流之上，遮挡商品卡底部信息，且滚动不消失。
   - 建议：改为可关闭或滚动自动收起，避免长期遮挡内容。

## 四、结论

首页本身的内容供给、信息架构和促销体系是成熟的，商品流质量高。但**新用户从冷启动到首页的这条路径存在两处强劝退点**（强制问卷 + 兼容性退出弹窗），叠加详情页白屏，会在拉新转化的最关键前几秒造成流失。优先级建议：先解决 P0 的问卷可跳过与兼容弹窗文案，再优化详情页首屏加载。

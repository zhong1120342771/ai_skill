## 聚合口径

- 完整聚合优先纳入 `valid` 样本。
- `partial_valid` 只能作为方向信号，不能和 `valid` 同权重。
- `invalid` 不纳入产品体验结论。
- 工具失败样本只作为工具风险记录，不作为产品体验强结论。
- 用户真实失败、犹豫、放弃可作为体验结果纳入。
- XML 屏外、Agent 推断和工具噪声不得写成用户已看到或产品强问题。

# 飞书文档格式规范

导购流程分析写入飞书文档的结构约定，对齐既有「转 APP 核心链路分析」文档里表 1-表 4 的格式。

## 章节结构（每个来源/主题一块）

```
h3 小标题（如「表5 5来源×分业务 完整链路：曝光→点击→商详→收银台→支付（dt=YYYY-MM-DD，App端）」）
  → 图片实体1：分业务×5来源 曝光→点击转化率
  → 说明段（p）：口径说明
  → 图片实体2：分业务×5来源 曝光→支付转化率
  → 数据表（table）：完整链路 20 行明细
```

图必须作为**图片实体**插入正文对应结论旁，紧跟其支撑的小标题/结论段。不允许只写「图X：xxx」文字，不允许把所有图堆到文末。

## lark-cli 写入要点（--as user）

**建文档**（markdown 导入）：
```bash
lark-cli docs +create --as user --doc-format markdown --title "..." --content @./doc.md
```
markdown 导入不落 `<title>`，显示 Untitled，建完后补一次 `str_replace` 刷标题。

**精确改块**（替换表格/段落）：
```bash
lark-cli docs +update --command block_replace --block-id <id> --content @./table.html
```
- 是 `+update --command block_replace`，**不是** `+block-replace`（不存在）。
- `--content @file` 路径必须 **cwd 相对**（先 `cd` 到文件所在目录用 `@./file`），绝对路径报 unsafe 静默丢内容。
- `block_replace` 会给被替换块分配**新 block-id**，改完必须重新 fetch 拿最新 id。

**取指定段落块 id**：
```bash
lark-cli docs +fetch --detail with-ids --scope section --start-block-id <id>
```
内容在 `data.document.content`（HTML 串）。

**插图片实体**：
```bash
lark-cli docs +media-insert --as user --file ./img.png --selection-with-ellipsis "<锚点正文句>"
```
- `--file` 只吃 cwd 相对路径，绝对路径报 unsafe 丢图。
- 锚点句要在正文里**真实且唯一**；图插到锚点句所在文本块之后。
- 图片块本身无文字，**不能**当 media-insert 的锚点。
- 判成功看 stdout 有 `"type":"image"`。

## 表格 HTML 约定（gen_table.py 产出）

- `<table><colgroup>...<thead>...<tbody>...</table>`，12 列（2 列名 + 5 UV + 5 转化率）。
- 纯整数单元格加千分位；百分比/文字保持原样。
- 默认剔除小计行，只留 20 明细。

## P2P 推送

分析结论 + 文档链接 P2P 推钟梦婷个人会话：
```bash
lark-cli im +messages-send --as bot --user-id ou_5e572adca6deef8ef21c3b18dfade573 --text "..."
```
P2P 用 `--user-id`（不是 `--chat-id`）。对外文字先过 humanizer 去 AI 味，数字/口径/结论不动。

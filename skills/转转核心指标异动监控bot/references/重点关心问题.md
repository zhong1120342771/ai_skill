# 重点关心问题（分析主线）

> 飞书真源：https://zhuanspirit.feishu.cn/wiki/FOWkwMs0HiFHwtk2jSZcqDqcnNA
> 本 bot 的分析主线就是这份文档。定位：一个专业的经营分析师，回答"今天的数据指标是否异常，如果异常是哪个环节异常、有没有特征维度"。

## 一、北极星指标（先看这三个是否异常）

1. **dau-净支付pv转化率**（产品侧核心关注）＝ `pay_pv / matched_dau_uv`
2. **dau**（活跃）＝ `matched_dau_uv`（整体行即全站 DAU）
3. **单量**＝ `pay_pv`（净支付pv）

北极星波动判定：上涨还是下降、幅度多大、环比（vs t-1 / vs 上周同日）怎样、同比怎样。

## 二、分析顺序（逐层下钻）

1. **先看北极星**：`整体` 行的三个北极星指标是否异常波动。
2. **再看漏斗环节**：`dau转化率 = 曝光渗透率 × 商详到达率 × 下单率 × 支付率`。逐环节对比同环比，定位北极星的波动是被哪个环节拉动的。
3. **最后拆维度找特征**：把异常拆到 业务（消费电子/兴趣/二奢）- 品类、端（App/小程序/找靓机）、场景、用户来源、用户资产（z1-z5），看哪个维度异常；异常的维度再进一步下钻（换含该维度的更高阶交叉族），定位到最细颗粒度。

## 三、产出结论要回答的问题（核心结论必答，按优先级）

1. **大盘是否异常**：今天大盘核心指标（三北极星）是否异常？如果异常，是**哪个环节**异常（曝光渗透/商详到达/下单/支付）？
2. **分业务是否异常**（仅次于大盘北极星的第一优先级，必答，必须进"结论先行"）：**消费电子 / 二奢 / 兴趣** 三大业务今日**各自是否异常**，逐个点名（正常 / 异常↓ / 异常↑）。
   - 判据：北极星 `dau_pay_rate` 或 单量 `pay_pv` 环比（上周同日优先、缺则 t-1）任一越 **±15%** 相对阈值即判异常；方向以北极星优先。由 `business_diagnose.py` 产出 `biz_diagnose_${dt}.csv` 的 `biz_anomaly` / `biz_anomaly_verdict` / `biz_anomaly_reason` 字段承载。
   - 异常业务要点出北极星或单量环比幅度、拖累环节，并优先下钻到品类；判"数据不足"的业务如实标注，不当正常也不当异常。
   - 兴趣＝整个兴趣业务口径（含长尾N），非仅长尾N类目。
3. **分场景是否降低**（改点3，必答）：各场景对**大盘**和**各业务**的**流量分发**（曝光UV + 曝光渗透率）与**转化效率**（提袋率＝商详到达率×商详转化率）今日是否降低。判据：环比（上周同日优先）任一 ≤ **-15%** 记为降低。由 `scene_diagnose.py` 产出 `scene_diagnose_${dt}.csv`。**若定位到某业务在某场景的流量或转化效率有问题，必须细拆到是哪个品类出的问题**（脚本自动下钻，报告要点名品类）。
4. **有没有特征维度**（异常集中在哪个业务/品类/端/场景/来源/资产层），下钻到最细颗粒度。

## 四、异动判定基准（三个都要看）

| 基准 | 说明 |
|---|---|
| 环比 vs t-1 | 分析日 vs 昨天 |
| 环比 vs 上周同日 | 分析日 vs 7 天前（消解周内节奏） |
| **同比 vs 去年同期（独立判定基准）** | 分析日 vs 去年同期，相对涨跌越 **±15%** 与环比并列计入异常。**对齐方式**：统一星期对齐（分析日 -364 天），大促峰值日的日期对齐特例已剔除（大促节点非用户输入）。真源 `calendar_context.yoy_baseline`。北极星等指标呈现时带出同比数值。 |
| **周环比的去年同期校验** | 周环比命中异动后，看去年同期同一组周环比（星期对齐 -364/-371）是否同向且量级相近 → 是则判**周期性回落**（发薪日/寒暑假等节律），非真异动 |

- **周环比异常必做季节性校验**：分析日 vs 上周同日的回落/上涨触发关注后，先查去年同期同一位置的周环比（`detect_anomaly.py` 自动产出 `seasonal`/`seasonal_verdict`）。去年同向且幅度相近（比值 [0.5,2.0]）＝周期性可解释，从真异动里剔除；去年反向或量级不匹配＝疑似真异动保留；去年数据缺失＝如实标注不臆断。口径细节见 [日历与季节性.md](日历与季节性.md) §二补。

- 幅度阈值默认北极星/漏斗环节 ±（相对）阈值触发关注；维度层横向对比用偏离中位数的 MAD 倍数。
- **比率必看体量**：小分母（`exp_uv`/`matched_dau_uv` 很小）下比率剧烈抖动，剔除小样本行；报告里给比率必附绝对量（曝光UV/商详UV/单量/DAU），让业务方读得出盘子大小。
- **口径别错**：`matched_dau_uv` 为 NULL 的行不能算 DAU 类比率（见 [字段映射与指标口径.md](字段映射与指标口径.md) §五）。

# 转转用户分层方案说明

> 来源：飞书文档 https://zhuanspirit.feishu.cn/docx/VkwQdxTTTobZ5xxHiLUcBV7rnpf  
> 版本：v1.0（2026-06）

---

## 一、框架：增强版 RFM（六维）

| 维度 | 含义 | 取数来源 |
|---|---|---|
| R | 最近一次净支付距今天数（分） | `dw_trade_order_company_all_detail_full_1d` |
| F | 近 180 天净支付笔数（分） | 同上 |
| M | 近 180 天净支付总额（分） | 同上 |
| L | 用户生命周期阶段（分） | `dm_oper_user_layer_dtl_inc_1d`（`regist_time`） |
| A | 近 30 天站内活跃行为深度（分） | `dm_oper_user_layer_dtl_inc_1d`（`visit_pv_30d`、`search_pv_30d`、`love_pv_30d`） |
| P | 价格敏感性（分） | `dw_trade_order_company_all_detail_full_1d`（`pack_amt`、`is_seckill_order`、`order_type`） |

综合评分公式：`score = R×2 + F×3 + M×1 + L×1 + A×2 + P×1`

---

## 二、各维度评分规则

### R — 最近一次支付间隔（0-3 分）

| 条件 | 得分 |
|---|---|
| 近 30 天内有净支付 | 3 |
| 31-90 天 | 2 |
| 91-180 天 | 1 |
| 无记录或 > 180 天 | 0 |

### F — 近 180 天支付频次（0-4 分）

| 条件 | 得分 |
|---|---|
| ≥ 5 笔 | 4 |
| 3-4 笔 | 3 |
| 2 笔 | 2 |
| 1 笔 | 1 |
| 0 笔 | 0 |

### M — 近 180 天支付总额（0-3 分）

| 条件 | 得分 |
|---|---|
| ≥ 10000 元 | 3 |
| 1000-9999 元 | 2 |
| 100-999 元 | 1 |
| < 100 元或 0 | 0 |

### L — 用户生命周期（0-3 分，基于 regist_time 推导）

| 条件 | 得分 |
|---|---|
| 注册 ≤ 30 天（窗口期新用户）| 1（特殊：成长上限有限，不给高分）|
| 注册 31-180 天（成长期）| 2 |
| 注册 > 180 天且有支付记录（成熟老用户）| 3 |
| 注册 > 180 天但从未支付（僵尸老用户）| 0 |

> 实现方式：`DATEDIFF('${dt}', DATE(regist_time))` 得注册天数；注册时间来自 `dm_oper_user_layer_dtl_inc_1d.regist_time`（字段格式 `yyyy-MM-dd HH:mm:ss`）。

### A — 近 30 天活跃行为深度（0-6 分）

直接取 `dm_oper_user_layer_dtl_inc_1d` 中现成字段，每项二元打分：

| 字段 | 触发阈值 | 得分 |
|---|---|---|
| `visit_pv_30d`（商详浏览） | ≥ 5 次 | 1 |
| `search_pv_30d`（搜索） | ≥ 3 次 | 1 |
| `love_pv_30d`（加购/收藏/下单） | ≥ 1 次 | 2（权重最高，意图最强） |
| `b2c_all_order_num_365d`（历史成交） | ≥ 1 笔 | 2（老买家信号） |

最高 6 分（四项全中）。

> 如需行业精细化（消电 / 二奢 / 兴趣 N 分品类），可扩展为 `core_visit_pv_30d`、`cate_visit_pv_30d` 等字段，一期先用整体口径。

### P — 价格敏感性（0-3 分，阶段一口径）

| 条件 | 得分 |
|---|---|
| 红包使用率 ≥ 50% 或 活动型订单占比（秒杀/砍价/降价拍/讲价买）≥ 30% | 3 |
| 红包使用率 30-50% 或 活动型订单占比 15-30% | 2 |
| 红包使用率 10-30% | 1 |
| 均不满足 | 0 |

活动型订单：`is_seckill_order=1` 或 `order_type IN (4,8,23)`；分期支付 `pay_type IN (105,108,109,110,111,1007,1012,1013,1016,1017)` 视同加 1 分（上限不超过 3 分）。

## 三、综合评分与五层分层

满分：R(3)×2 + F(4)×3 + M(3)×1 + L(3)×1 + A(6)×2 + P(3)×1 = 6+12+3+3+12+3 = **39 分**

| 层级 | 名称 | 得分区间 | 预估用户占比 | 核心特征 |
|---|---|---|---|---|
| L5 | 超级核心 | ≥ 28 | ~0.3-0.5% | 高频高价值，近期活跃，价格不敏感 |
| L4 | 高价值活跃 | 20-27 | ~3-5% | 有多次成交，近期活跃，是核心盘 |
| L3 | 潜力培育 | 13-19 | ~10-15% | 有成交但频次低或近期沉默 |
| L2 | 低活跃兴趣 | 7-12 | ~25-30% | 有浏览无成交或唯一成交 |
| L1 | 沉睡/无价值 | 0-6 | ~50-60% | 长期无活跃，未成交 |

## 四、9 个特征人群（圈选逻辑）

| 人群 | 圈选条件 | 优先级 |
|---|---|---|
| 高频金主 | L ≥ L4 且 F_score=4 且 M_score≥2 | 高 |
| 价值回流 | R_score=0 且 历史 F_score≥3（用 `b2c_all_order_num_365d ≥ 3`） | 高 |
| 新用户活跃 | L_score=1（注册≤30天）且 A_score≥3 | 高 |
| 搜而不买 | A_score(search)=1 且 A_score(love)=0 且 F_score=0 | 中 |
| 加购未付 | A_score(love)=2 且 F_score=0 | 中 |
| 沉睡老客 | b2c_all_order_num_365d≥1 且 R_score=0 | 中 |
| 高价值二奢 | M_score=3 且 order 品类含二奢（`cus_business_bu='二奢'`） | 中 |
| 价格敏感高频 | P_score=3 且 F_score≥3 | 专项 |
| 分期依赖 | 分期订单占比 ≥ 30% 且 M_score≥2 | 专项 |

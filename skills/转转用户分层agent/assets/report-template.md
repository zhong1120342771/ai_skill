## 一、分层方案说明

### 1.1 框架概述

转转用户分层基于增强版 RFM 六维打分：

| 维度 | 含义 | 权重 |
|---|---|---|
| R — 近期度 | 最近一次净支付距今天数 | ×2 |
| F — 频次 | 近 180 天净支付笔数 | ×3 |
| M — 价值 | 近 180 天净支付总额 | ×1 |
| L — 生命周期 | 注册时间段（新用户/成长期/老用户） | ×1 |
| A — 活跃深度 | 近 30 天站内行为（浏览/搜索/加购/收藏） | ×2 |
| P — 价格敏感性 | 红包使用率 + 活动型订单占比 | ×1 |

综合评分 = R×2 + F×3 + M×1 + L×1 + A×2 + P×1，满分 39 分。

### 1.2 五层定义

| 层级 | 名称 | 分数段 | 核心特征 |
|---|---|---|---|
| L5 | 超级核心 | ≥ 28 | 高频高价值，近期活跃 |
| L4 | 高价值活跃 | 20-27 | 多次成交，主力购买力 |
| L3 | 潜力培育 | 13-19 | 有成交但频次低或近期沉默 |
| L2 | 低活跃兴趣 | 7-12 | 有浏览无成交或唯一成交 |
| L1 | 沉睡/无价值 | 0-6 | 长期无活跃，未成交 |

## 三、运营策略

### L5 超级核心（${L5.pct}%）

**策略：保留 + 特权**

- 优先投入专属权益（VIP 通道、优先客服、专属折扣）
- **禁止**：高频推送打扰、促销叠加降质感
- 监控流失预警：R 维度由 3 分降为 2 分时触发挽留

### L4 高价值活跃（${L4.pct}%）

**策略：拉升至 L5**

- 圈选条件：`segment_level='L4'`，周期投放品质内容 + 限时专属活动
- 机会点：提高支付频次（F 维度 3→4）或提升客单（M 维度 2→3）均可升层
- 参考转化率：L4 内近期支付用户 30 天复购率（待数据验证）

### L3 潜力培育（${L3.pct}%）

**策略：激活购买意图**

- 搜而不买子群（${p_搜而不买}）：精准推搜索过品类的相关商品降价提醒
- 加购未付子群（${p_加购未付}）：加购后 3 天内触达，高效意图转化窗口
- 避免无差别大促，容易被价格锚点固化，后续难做复购

### L2 低活跃兴趣（${L2.pct}%）

**策略：低成本唤醒**

- 价格敏感用户（P ≥ 2）：推活动信息效率更高
- 行为稀少用户：用轻触达（Push 而非弹窗）保持品牌存在感
- ROI 预算适中，不做大投入

### L1 沉睡（${L1.pct}%）

**策略：分批激活 + 定期清洗**

- 价值回流人群（${p_价值回流}）：历史有成交，激活成功率最高，优先圈
- 纯沉睡无购买历史：低成本 Push，激活成本控制，不建议大促覆盖
- 每季度清洗无响应的 L1，降低骚扰率
